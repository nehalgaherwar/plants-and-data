# 🌿 Beautiful Plants Website

A simple and elegant static website that showcases the beauty of plants and nature.  
Built using **HTML, CSS, and JavaScript**, this project is perfect for beginners learning frontend web development.

---

## 📖 About the Project

The **Beautiful Plants** website introduces users to the world of plants through a visually pleasing layout.  
It features a hero section, featured plants, interesting plant facts, and a clean footer.

---

## ✨ Features

- 🌱 Responsive and clean layout  
- 🌼 Hero section with call-to-action button  
- 🌻 Featured plants with images and descriptions  
- 📚 Fun and educational plant facts  
- 🎨 Easy to customize design  
- 🚀 Beginner-friendly project structure  

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the website  
- **CSS3** – Styling and layout  
- **JavaScript** – Basic interactivity
